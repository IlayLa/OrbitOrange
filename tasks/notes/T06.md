## Decisions

- **T06 never chooses the launch stages.** `MissionPlan.launch_stage_ids` belongs to the tick box of the orbit planning screen (T05). So after building an engine and a tank, Launch stays disabled with the reason "No stage fires at launch." until T05 is merged, or until "Build example rocket" is pressed. Yasha chose this over adding the first stage automatically. The task's manual check "building an engine plus a tank enables Launch" therefore needs T05 as well.
- **"Build example rocket" stays** in the top bezel. T09's stub had it, and it is the only way to enable Launch before T05. Remove it when T05 lands if the team wants.
- **Launch is disabled only by `summary.blocking_problems`.** Advice (`"Warning:"`) and going over budget never disable it. Blocking problems are shown in red, the other warnings in white.
- **Over budget:** the cost chip turns red and shows the points lost against spending exactly the budget: `Scoring.budget_points(budget, budget) - Scoring.budget_points(cost, budget)`.
- **Which stage gets a tank:** the selected liquid stage; with none selected, the highest liquid stage without a tank; with no liquid stage, nothing is installed and the free cell says why. A new liquid stage is selected automatically. The player changes the selection with the stage tags ("S1", "S2") left of the stack. A tank on a stage that already has one replaces it.
- **Removing parts in the preview:** a click on an engine removes its whole stage, on a tank only the tank, on a payload part that part. Removing a stage also removes its id from `launch_stage_ids` and deletes its pulses, then calls `notify_design_changed()` and `notify_plan_changed()`.
- **Mission-fit stars** are shown for science parts only, for `GameState.science_mission_id`. Other categories have no rating.
- **The tabs have no text of their own:** the mock-up already writes ENG, MAT, TEL and SCI. The buttons add an orange frame for the chosen tab.
- **No vehicle art.** The stack is drawn in code from the part icons; `assets/placeholders/vehicle/` was not needed and does not exist.

## Requests to the integrator

1. **Right-to-left computers show empty screens (whole project, not only T06).** On a computer whose language is written right to left (Hebrew on Yasha's machine), Godot mirrors every `Control` whose `position` is set before `add_child`. All screens of the game are built that way, so they render empty; running with `--language en` shows them correctly. Please add to `project.godot`, section `[internationalization]`:
   `rendering/root_node_layout_direction=1` (left to right), or fix the locale to `en`. Until then `T06Demo.gd` and the T06 test call `TranslationServer.set_locale("en")` themselves (the test puts the old locale back); `PlanningConsole.gd` and `RocketDesign.gd` only set their own `layout_direction`, which is not enough by itself. T06 did not edit `project.godot`.
2. **`BACK_BUTTON_RECT` overlaps the first category tab by 6 pixels** (`y` 34 to 56 against the ENG tab from `y` 50). It still works; moving the tab rectangles or the button is the integrator's call.
3. **`TestRunner.gd` hangs when a test file has a parse error:** `load` returns null, `_ready` stops at `.new()`, and `quit` is never reached. A null check with a failed check and a `quit(1)` would make `check_project.sh` fail fast instead.
4. Setting `size` on a `Button` or `Label` right after a font-size override is ignored until the end of the frame, because Godot still measures the text with the default font. `PlanningConsole._set_size_when_font_is_known` and `StatChips._apply_line_sizes` set the size again deferred. Other screens with small fixed rectangles may need the same.

## How to check by hand

Open `res://scenes/development/T06_demo.tscn` and run the scene.

- Click the left monitor: the rocket design screen zooms in. Add an engine and a tank: all three chips change. Hover a card for the popup. Click an installed part to remove it. Esc or "< BACK" zooms out.
- Launch shows "Cannot launch: No stage fires at launch." (expected, see Decisions). "Build example rocket" enables it.
- Add several "Imaging radar" parts under SCI: the cost chip turns red with a penalty and Launch stays enabled.
- Click the right monitor: the orbit planning screen (T05's stub for now) zooms in with its own chips.
- Launch hands over to the EXECUTION half only through `scenes/Console.tscn`.

Rendered pictures of every screen: run the demo with a window and `-- --capture-directory=<absolute folder>`.
