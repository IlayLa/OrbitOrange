# References

The NASA Space Apps rules require every external resource to be cited, including open-source and freely available ones. A team can lose a nomination for a missing citation.

**Each task writes its own file** in `docs/references/`, so that no two agents edit the same file:

| File | Covers |
|---|---|
| `references/T00.md` | The skeleton, the contracts and the plan |
| `references/T01.md` … `T08.md` | One per task |

## What counts as an external resource
Anything the team did not make during the hackathon: data sources (every `source` in `data/parts.json`), documents and formulas, code, images, fonts, sounds, and tools such as the game engine.

## What each entry records
- name,
- URL,
- licence or terms of use,
- where in the project it is used.

Non-NASA material must be freely and publicly available or under an open-source licence. If you cannot find the licence of something, do not use it.

**A change that uses an external resource is not finished until its entry is written, in the same commit.**
