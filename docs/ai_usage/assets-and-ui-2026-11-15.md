# AI use: team art, interface and readability (2026-11-15)

Covers pull requests #8, #9 and #13 to #34, all opened and merged by Yasha on 15 November 2026. The commits that the AI wrote carry a `Co-Authored-By: Claude Opus 5.5` trailer; commits without that trailer were made by hand.

## Common to every session below

- Tool: Claude Code (Anthropic), desktop app, with shell, file editing and Godot 4.7.2. Model: Claude Opus 5.5, as named in each commit's trailer. Several sessions ran at the same time, each in its own git worktree (branches named `claude/...`), and were merged through the integration branch `implement-our-assets` (#30).
- Asked by: Yasha, who chose each task, the order of the work and the look, and merged each pull request.
- Images: **no image was generated by an AI model.** The source art in `design/` was supplied by the team (the part sprites, Amit's portraits, the end-screen mock-ups, the font sheet and the button sheet were committed by team members). The AI wrote Godot scripts that cut, centre, scale and place that art (`tools/build_part_icons.gd`, `tools/build_button_skin.gd`, `tools/build_pixel_font.gd`), and the code that draws glyphs, lamps, the orbit schematic and the rocket stack.
- Validation: each session ran `tools/check_project.sh` before its pull request, and the sessions that changed a screen captured it with `tests/playtest/CaptureScreens.tscn` (captures in `docs/screenshots/`). Each pull request's description lists its own checks.
- Human review: Yasha looked at the screens in the game and merged each pull request. No pull request has a written GitHub review.
