## What is not from a source
Every cost is a game value scaled to the mission budget, not a real price. Sensor noise, update rates, dropout probabilities, radar ranges below the top tier, science values, power and data rates are game values. The fuel gauge, the temperature sensor, the two computers, the cameras, the atmosphere probe and the imaging radar have estimated masses. Each part's `source` text says so, and every part has `is_approximate` set to true.

The Tsiolkovsky rocket equation is standard textbook physics and needs no licence.
